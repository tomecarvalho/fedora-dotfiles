# Installation Groups

| Group    | Description                                                      | Packages                            | Script                                       |
| -------- | ---------------------------------------------------------------- | ----------------------------------- | -------------------------------------------- |
| General  | Tools I always need and general system configuration.            | [`general`](../packages/general/)   | [`general`](../scripts/install/general.sh)   |
| Optional | Additional tools I might not need, particularly if dual booting. | [`optional`](../packages/optional/) | [`optional`](../scripts/install/optional.sh) |
| Work     | What I only need for work.                                       | [`work`](../packages/work/)         | [`work`](../scripts/install/work.sh)         |

Run the script of the desired installation group to install it.
